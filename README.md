# 🐷 John Pork in Brainrot Language 📱💬

> *"The call is coming from inside the compiler..."* 📞⚡

Bem-vindo ao repositório oficial do **John Pork in Brainrot Language**, o único projeto que une a lendária entidade **John Pork** à linguagem de programação mais *skibidi* da Web3.

---

## 🌟 O que é isto?

Este projeto é uma implementação/interpretador da linguagem **Brainrot**, totalmente tematizada com o universo de memes do **John Pork**. Se alguma vez quiseste escrever código que faz um *Rizz Check*, faz o *Mewing* do teu loop ou simplesmente recebe uma chamada do John Pork quando ocorre um erro fatal, vieste ao sítio certo.

---

## 🚀 Funcionalidades (Features)

* **John Pork Call Handling**: Lança exceções como chamadas de entrada (`John Pork is calling...`).
* **Ohio Error Syntax**: Erros de sintaxe são redirecionados diretamente para Ohio.
* **Mewing Optimizer**: Otimização de código que mantém a tua função em silêncio absoluto para máxima eficiência.
* **Gyatt GC (Garbage Collector)**: Limpa a memória RAM sem perder o *aura points*.

## 📜 Sintaxe Básica (Syntax Cheat Sheet)

| Conceito Tradicional | Sintaxe Brainrot / John Pork |
| :--- | :--- |
| `print("Hello World")` | `talkToThePig("Hello World")` |
| `if (condition)` | `isItRizzing(condition)` |
| `else` | `downInOhio` |
| `while (true)` | `edgeUntilSuccess` |
| `return` | `answerTheCall` |
| `break` | `hangUp` |
| `null / undefined` | `noAura` |

## 💻 Exemplo de Código (`main.rot`)

```brainrot
// Definir a presença do John Pork
let porkAura = 9999;

isItRizzing(porkAura > 9000) {
    talkToThePig("John Pork is calling! Pick up the phone!");
} downInOhio {
    talkToThePig("No aura detected. Hang up.");
}

// Loop de Mewing
edgeUntilSuccess {
    porkAura += 1;
    isItRizzing(porkAura == 10000) {
        hangUp;
    }
}

answerTheCall porkAura;
```
